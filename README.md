# Tâilingo

以教育部《臺灣台語推薦用字 700 字詞》為內容的台語學習小遊戲（純前端，單一 `index.html`，進度存在瀏覽器 localStorage）。

## 功能

- 700 字詞，每 10 個詞一課，依臺羅拼音字母排序
- 題型：詞→意思、詞→拼音、意思→詞、拼音→詞、用例填空
- 答錯的字稍後換題型再出現；間隔複習（10 分鐘、1、2、4、8、16 天）
- 今日一詞、連續天數、XP

  也未經教育部背書。
- 發音音檔來自教育部[臺灣台語常用詞辭典](https://sutian.moe.edu.tw/)。本專案**只儲存音檔的連結**，
